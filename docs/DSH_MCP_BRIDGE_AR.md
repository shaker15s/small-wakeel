# جسر WAKIL المحلي مع DeepSeek Harness

حزمة تجربة محلية منفصلة: [integrations/dsh-wakil](../integrations/dsh-wakil/README.md).

الخادم يتصل بقاعدة WAKIL محلية مستقلة خارج Git، ويعرض allowlist للقراءة وأدوات prepare-draft فقط. لا يوجد في بروتوكول MCP أي أداة اعتماد أو تنفيذ نهائي.

يجب اختيار Profile مستقل في DSH. Creator Mode أداة تطوير وليس وضع صاحب النشاط اليومي. يجب إعداد متغيرات البيئة قبل تحميل الحزمة لأن DSH يقرأها أثناء تكوين MCP Client.

لا تستخدم قاعدة العرض المتتبعة أو بيانات عمل حقيقية قبل التدقيق الأمني والقانوني والاختبارات الحية المنفصلة.
