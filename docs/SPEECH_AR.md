# الصوت (STT) — خط الصوت في وكيل (PR-014 / الخطة §11.3)

## الحالة الصريحة
| البند | الحالة | الدليل |
|---|---|---|
| خط STT عبر مزود معتمد | `implemented` (عقد الـ adapter) | `tests/integration/speech-pipeline.test.ts` على mock ASR |
| مزود STT **فعلي** (Live) | **`not_connected`** — غير مُفعَّل | لا يوجد مزود إنتاجي مثبت؛ `GET /api/speech` يعرض `available` من قاعدة الإعداد فقط |
| قبول صوتي حي (live acceptance) | **غير منفَّذ** — `liveAcceptance:false` في أي تقرير mock | القبول الحي يتطلب تسجيلًا حقيقيًا بموافقة صريحة + `WAKIL_VOICE_AUDIO`/`WAKIL_VOICE_EXPECTED` (انظر `scripts/live-voice-acceptance.ts`) |
| تحويل الصوت إلى إجراء مالي | **ممنوع بنيويًا** | النص يُرجع للمستخدم للمراجعة فقط؛ لا Operation ولا Message ولا AgentEvent — مُختبر |

## نموذج الثقة (كل بند مُختبر في `tests/integration/speech-pipeline.test.ts` و`tests/integration/speech.test.ts`)
| الضمان | التنفيذ |
|---|---|
| الموافقة صريحة في كل طلب | هيدر `x-wakil-audio-consent: review-only` إلزامي؛ بلاه = 400 — لا يُستنتج شيء من أي سياق |
| مراجعة إلزامية | الرد `reviewRequired: true` دائمًا — النص **لا** يتحول تلقائيًا لرسالة ولا موافقة |
| حدود النوع | whitelist من 6 أنواع + فحص magic bytes (RIFF/WAVE, ftyp, ID3/0xFF, webm, OggS) — نوع مزوّر = 415 |
| حدود الحجم | 4MB كحد أقصى (هيدر + تدفقي) — 413 |
| صمت = خطأ صادق | تسجيل بلا كلام يُرجع خطأً عربيًا صريحًا («ما اتلقطش كلام واضح») — **لا نص مُختلَق** |
| لا مفاتيح في الرد | مفتاح المزود مُشفَّر server-side؛ الـ 500/4xx لا تحرقه أبدًا (مُختبر) |
| ephemeral token (Live client-to-server) | `POST /api/speech/session` يصدر `wsp_…` صالح **60 ثانية** و**stt فقط**؛ العميل لا يرى أي API key دائم |
| نطاق الـ token | يُقبل فقط في `POST /api/speech`؛ لا يفتح أي كتابة/موافقة/جدولة |
| عزل المستأجر | الإصدار يمر بـ `guard` (business scope) — أي مستخدم مسجَّل في المنشأة؛ audio نفسه بلا حالة محفوظة |
| الحوسبة المالية | **خارج** خط الصوت بالكامل: لا parsing مالي من الصوت، لا `Operation`، لا تغيير مخزون/سعر/رصيد |

## مسار الطلب
```
المالك يسجّل صوتًا (موافقته صريحة)
   → POST /api/speech  (هيدر الموافقة + audio ≤4MB + نوع مسموح)
   → guard (business scope) أو ephemeral token (stt فقط، 60s)
   → مزود ASR المعتمد في SpeechSettings id='global' (baseUrl + مفتاح مُشفَّر)
   → { text, reviewRequired:true, ms, costUsd }
   → المالك يراجع النص → يرسله كرسالة عادية → من هنا فقط تدخل منطق الأعمال
```
لا يوجد أي مسار من `text` مباشرة إلى أداة: نفس قواعد المحادثة المكتوبة تنطبق (approval لكل إجراء له أثر مالي).

## الكلفة والسرعة — كيف نعرف أننا «معلومة»
- `ms` = زمن القياس الفعلي لكل نداء (من بدء القراءة حتى اكتمال الرد).
- `costUsd` = تقدير من سعر المزود **إذا كان مثبتًا** (لكل دقيقة صوت × التقدير بالمدة)؛ بلا سعر مثبت = **0 صادق** — لا رقم مختلَق.
- الـ SLO المستقبلي (الخطة: <2s P50، <5% فشل) **بوابة إطلاق مستقبلية** — لا ندّعيها الآن؛ أي ادعاء قبل قياس حي = ممنوع.
- الدليل الحالي (mock): زمن ~25ms على الشبكة المحلية — **دليل عقد adapter فقط** (`liveAcceptance:false`)، ليس قبولًا لخدمة صوتية حقيقية.

## ما الذي **لم** يُفعَّل (وبقية الشغل)
1. **مزود STT حي** — اختيار مزود إنتاجي + ثبات الأسعار + `scripts/live-voice-acceptance.ts` بتسجيل حقيقي موافق عليه (الاسم/المبلغ/التاريخ) = شرط `Live`.
2. **TTS** (رد صوتي) — غير موجود أصلًا؛ لا نعرضه ولا نلمّح إليه.
3. **Multi-process session store** — الـ token map في الذاكرة؛ أي توسعة لأكثر من runtime تحتاج نقله للـ cache المشترك (موثّق هنا، لا يُفترض صامتًا).
4. **اقتراح السعر غير المسجل بصوت** — «السعر كام يا عم؟» من كلام العميل يُعامل كمعلومة بشري موثوق بها: يُسجل في facts بمصدره وثقته، ولا يُخمن (قاعدة الخطة: المجهول يبقى «غير مسجل»).

## التشغيل (tuning)
- `WAKIL_SPEECH_SESSION_TTL_MS` — صلاحية الـ ephemeral token (افتراضي 60000).
- `WAKIL_ALLOW_LOCAL_PROVIDERS=1` — تطوير فقط: يسمح بـ baseUrl على 127.0.0.1 (محظور في الإنتاج — `provider-network` يرفض «Non-public»).
- mock ASR محلي: `bash mini-services/mock-provider/start.sh` → `POST /v1/audio/transcriptions` (صمت/أقل من 100 بايت → `{"text":""}`؛ وإلا جملة حتمية من محتوى الملف).
